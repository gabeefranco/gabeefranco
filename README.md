I'm **Gabriel Franco**, a computer science student at **PUCRS** (Pontifícia Universidade Católica do Rio Grande do Sul).

I care about computer science as a field, not just as a set of tools for shipping products. I'd rather understand a system properly than memorize the steps to make it work, so I tend to slow down on purpose and figure out what's actually happening under the hood, whether that's a compiler, an operating system or a language runtime.

I'm also interested in the history of the open source movement: the people, the arguments and the decisions that shaped the software we all rely on. Knowing where a tool came from usually explains a lot about how and why it works the way it does today.

My blog is bilingual. Every post is available in English and in Portuguese.

## 🧠 What I'm interested in

- **Operating systems**: kernels, Linux, and how the system works under the userland
- **Compilers & language runtimes**: how source code turns into something a machine runs
- **Open source history & culture**: GNU, Linux, free software and the people behind them
- **Security**: understanding exploits by reproducing them
- **Software & its users**: what software is turning into, and what it should be
